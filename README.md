# Paisa — Personal Finance Parser + Dashboard

> **Status:** ✅ Solid spec. Ready to build.
> **Platform:** CLI + Web dashboard
> **Stack:** Rust parser + Next.js dashboard
> **Effort:** ~88 hours full, ~30 hours MVP

A local-first personal finance parser and dashboard built around the Paisa Standard Format.
It turns bank and UPI statements into a consistent shape, then shows where the money
actually went. Statements never leave the machine.

Full spec: [docs/spec.md](docs/spec.md)
